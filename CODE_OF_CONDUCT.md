# Code of Conduct

Agent Theories is intended to support rigorous, open, evidence-aware discussion of theories across domains.

Participants should:

- argue ideas rather than attack people,
- represent uncertainty honestly,
- cite authoritative sources,
- distinguish evidence from speculation,
- avoid misinformation and fabricated references,
- respect intellectual property and licensing obligations.

The project welcomes disagreement when it is constructive, evidence-aware, and clearly reasoned.
